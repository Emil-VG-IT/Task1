# JavaScript
Jeg har laget en liste med spørsmål og svaralternativer.
Hvert svar har en correct verdi som forteller om svaret er riktig eller feil.

Når quizen starter, vises det første spørsmålet.
Riktig svar blir grønt, og feil svar blir rødt.

Etter at brukeren har svart, kommer en Next knap frem og hover stoper å funke og Når alle spørsmålene er besvart, vises resultatet.
